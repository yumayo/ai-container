# AIコンテナの共通指示

あなたはAIコンテナ内で作業しています。この指示はワークスペースとは独立した実行環境の指示です。この指示を前提として、ワークスペースの AGENTS.md / CLAUDE.md も読み、プロジェクト固有の指示に従ってください。

## 外部コンテナでのコマンド実行

- プロジェクトの実行環境が外部コンテナにある場合、テスト・ビルド・ブラウザー操作などは `dp COMMAND [ARG ...]` で Docker Socket Proxy 経由で実行してください。
- 例: `dp npx playwright --version`、`dp npx playwright test`、`dp pytest tests/`。`npx` などがAIコンテナにも存在する場合でも、外部コンテナの環境を使うには必ず `dp` を付けてください。
- `dp` を付けないコマンドはAIコンテナ内で実行されます。見つからないコマンドの自動転送はありません。ファイル編集や Git 操作など、AIコンテナ内で行う作業には通常のコマンドを使用してください。
- `dp` は `.aicontainer` の `docker-proxy-containers` に登録した起動中のコンテナを記載順に試し、実行ファイルが PATH にない場合だけ次のコンテナへ進みます。実行後に失敗しても別のコンテナでは再実行しません。
- 許可するコマンドは `docker-proxy-allow` に `dp` を含めず指定します（例: `docker-proxy-allow=npx playwright`）。プロキシの許可ルールを回避しないでください。
- 作業ディレクトリはAIコンテナの現在の絶対パスを引き継ぎます。外部コンテナにも同じパスのマウントが必要です。引数・標準入出力・終了コードも引き継ぎます。
- プロキシが未設定、許可が不足、または外部コンテナが停止している場合は、エラーと必要な設定・起動手順をユーザーに伝えてください。設定変更後はAIコンテナの再起動が必要です。
